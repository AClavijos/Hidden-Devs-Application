# Hidden-Devs-Application

A single-script Roblox showcase demonstrating a broad range of server-side scripting concepts including CFrame math, physics simulation, pathfinding, metatables, and RunService-driven animation, organized
across six independently togglable systems. There are a couple of missing parts that i moved to my local scripts just to be able to use inputs, but I did not upload them since i dont think its necessary.
